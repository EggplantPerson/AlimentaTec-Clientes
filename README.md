# Requisitos

Node.js
pnpm
Expo
Expo Go en el dispositivo móvil si se desea ejecutar mediante un teléfono físico.

# Instalacion y ejecucion

1. Clonar la rama dev del repositorio
2. Instalar las dependencias con pnpm install desde la carpeta raiz del proyecto
3. Ejecuta en terminal pnpm start, Expo iniciará el servidor de desarrollo y mostrará un código QR.
4. Instala Expo Go en el teléfono, conecta el teléfono y la computadora a la misma red Wi-Fi
5. Escanea el código QR mostrado por Expo, la aplicación se abrirá en Expo Go.

También es posible ejecutar la aplicación en un navegador con pnpm web
Puedes iniciar el servidor limpiando la caché con pnpm exec expo start -c
